# Live Demo

Open PaperworkPilot at:

https://paperwork-pilot-ai.replit.app/

For the quickest review, keep **Parking permit** selected and click **Run selected demo**. Inspect the saved human checkpoint, then choose **Approve and resume agent** to view the source-linked requirements, missing information, supporting documents, warnings, and ordered checklist.

The included demonstration scenarios are fictional and can be run without an API key or personal paperwork.
